# YAPP Coding Conventions

Kotlin·Gradle Kotlin 변경에는 [Wiki 코딩 컨벤션](../../../docs/wiki/coding-conventions.md)과 [서식 설정](../../../.editorconfig)을 적용한다. 파일·패키지 배치는 [Wiki 모듈 구조](../../../docs/wiki/module-structure.md)를 따른다.

변경 파일과 호출부를 읽고 기존 수정 사항을 보존한다. 실패 위험이 있는 동작을 검증하고 실제 실행 결과를 보고한다. 새 규칙이 확정되면 [Wiki 갱신 절차](../../../docs/wiki/README.md)에 따라 같은 작업에서 기록한다.
