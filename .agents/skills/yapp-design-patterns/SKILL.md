# YAPP Design Patterns

화면·상태·요청·Repository·화면 이동의 기준은 [Wiki 설계 패턴](../../../docs/wiki/design-patterns.md)이다. 계층 경계는 [Wiki 아키텍처](../../../docs/wiki/architecture.md), Kotlin 서식은 [Wiki 코딩 컨벤션](../../../docs/wiki/coding-conventions.md)을 함께 읽는다.

업무 정책, 상태 전이, 매핑과 오류 처리의 경계 조건을 검증한다. 확인된 패턴 변경은 [Wiki 갱신 절차](../../../docs/wiki/README.md)에 따라 기록한다.
