# 회원·역할 정책

회원과 기수·직군 용어는 YAPP 정관 ver 6.0 (2026)과 운영세칙 ver 6.0 (2026)을 기준으로 합니다. 상세 기준은 [용어 정의서 2026](https://app.notion.com/p/yapp-workspace/2026-3fa2106a0e84802e8e37d0e9ffee3fb9)과 [화면 및 기능별 정책 2026](https://app.notion.com/p/yapp-workspace/2026-3fa2106a0e84800f9abfef181b090892)에 정리되어 있습니다.

## 앱 역할과 회원 자격

앱의 역할은 앱 기능에 대한 권한(authorization)이며 정관상 회원 구분과 일대일로 대응하지 않습니다. 특히 활동회원과 활동 정회원은 서로 다른 개념입니다.

활동회원은 특정 기수와 직군에서 활동하는 회원으로, 해당 기수 세션에 참여하고 수료 대상이 됩니다. 2026 용어 정의서는 이 활동회원을 정관 제5조 1호의 회원과 연결하며, 정관의 활동 정회원과는 다른 개념이라고 구분합니다. 활동 기록은 기수별이므로 같은 회원이라도 기수에 따라 활동회원 자격이 다를 수 있습니다. STAFF 직군은 활동회원에서 제외됩니다. 세션 출석 대상은 활동회원 역할, 해당 기수 활동 기록과 세션 대상 지정 기준을 함께 따릅니다. OB와 프로젝트에 참여하는 운영진의 출석 자격은 [제품 정책](product-policy.md)의 미확정 항목입니다.

## 정관상 회원 구분

| 구분 | 기준 |
| --- | --- |
| 회원 | 선발 절차를 거쳐 정식 가입해 활동 중인 인원 |
| 수료회원 | 수료 심사 기준 중 하나를 충족한 회원. 기준은 활동 기간 종료 전 프로젝트 런칭 또는 출석 점수 70점 이상입니다. |
| 정회원 | 필수 활동 기간 4개월 이상을 이수하고 수료 심사 기준을 모두 충족한 회원입니다. 총회 의결권이 있고 수료증 발급 대상입니다. |
| 활동 정회원 | 정회원 자격 취득일로부터 6개월 유효기간 안에 있는 회원입니다. 총회 개회 정족수에 포함됩니다. |
| 졸업 정회원(OB) | 활동 정회원 기간이 끝난 정회원입니다. 새 기수에 활동회원으로 참여하면 활동회원과 같은 운영비를 내며, 운영진 역할의 OB는 면제됩니다. 별도 출석 규정이 적용됩니다. |
| 유예 회원 | 질병 등 이사회가 인정한 사유로 활동을 유예해 자격을 유지하는 회원입니다. 다음 기수에 한해 선발 절차 없이 복귀할 수 있습니다. 필수 활동 기간 4개월을 채우지 못한 경우 복귀 분담금은 차기 운영비의 절반이며, 장기 입원과 병역은 예외입니다. |

수료 기준과 출석 점수는 [제품 정책](product-policy.md)을 따릅니다. 유예 사유 인정과 복귀는 정관·운영세칙의 절차를 따르며 앱의 자동 판정으로 대체하지 않습니다.

## 운영진·직책·직군

운영진은 실무 운영 담당자를 뜻합니다. 회장·부회장·이사는 당연직 운영진이고, 활동 정회원 중에서 실무 운영진을 선발할 수 있습니다. 감사는 운영진에 포함되지 않습니다. 직책은 운영진의 실무 직함이며 회장(CEO), 부회장(COO), CSO, CCO, CDO, CTO, CFO, CMO, 직군별 최대 2명의 TL이 있습니다.

한 기수 동안 담당하는 분야는 직군(Position)으로 기록하며 앱 권한 역할과 구분합니다. 2026 용어 정의서는 정관상 직군을 PM, 디자인, Web, iOS, Android, Server, AI Native로 기재합니다. 문서에는 Flutter가 이전 기수 활동 이력 예시로도 남아 있으나, Flutter를 과거 이력에만 유지할지는 확인이 필요합니다. 확정 전 직군 값의 이관이나 삭제를 임의로 결정하지 않습니다.

기수는 YAPP 활동의 한 주기입니다. 연 2회 운영하며 특별한 사정이 없으면 5월과 11월 첫째 주에 시작하고, 기수당 약 6개월입니다. 운영진은 3월과 9월부터 활동합니다.

## 동아리 탈퇴·제적과 앱 계정 삭제

- 동아리 탈퇴는 회원이 스스로 YAPP을 떠나는 것입니다. 재가입은 원칙적으로 불가하고 이사회 의결로 승인할 수 있으며, 이미 납부한 회비는 환불하지 않습니다.
- 제적은 이사회 심의로 동아리 자격을 박탈하는 것입니다. 재가입할 수 없고 납부한 회비도 환불하지 않습니다.
- 앱 회원탈퇴는 YAPP Official 앱 계정을 삭제하는 동작입니다. 동아리 탈퇴나 제적을 의미하지 않습니다. 화면에서는 앱 계정 삭제와 동아리 회원 자격 변경을 구별해 안내합니다.

현재 앱은 Google 계정을 Supabase Auth에 연결합니다. 새 인증 뒤 표시하는 이름·휴대폰 입력과 임시 가입 완료 흐름은 YAPP 회원 등록을 처리하지 않으며, 이름·휴대폰을 서버에 전송하지 않습니다. 실제 회원 자격, 앱 권한 부여, 동아리 탈퇴, 제적 또는 계정 삭제를 처리하는 서버 연동은 별도 API 계약이 마련된 뒤 구현합니다. 회원 정보 API가 연결되기 전까지 앱은 임의의 프로필·출석 값을 표시하지 않습니다.
