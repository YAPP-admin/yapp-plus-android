# 제품 정책

출석 기능의 동작은 확인된 요구사항과 API 계약을 기준으로 정합니다. 클라이언트가 보여주는 진행·예상 상태와 서버가 확정한 출석 결과를 구분합니다. 이 원칙은 출석 판정 기준이나 서버 응답 형식을 정한 것이 아닙니다.

## 아직 정해지지 않은 항목

| 항목 | 현재 상태 | 구현에 필요한 결정 |
| --- | --- | --- |
| 출석 판정 | 미확정 | 세션 식별, 시간·위치·코드 조건, 중복·지각·결석 처리 |
| 출석 API | 미확정 | 엔드포인트, 인증 방식, 요청·응답, 오류·재시도 계약 |
| 인증 | 미확정 | 가입·로그인 흐름과 토큰 관리 정책 |
| 로컬 저장 | 미확정 | 보존할 데이터와 기간, 동기화·삭제 규칙 |

미확정 항목을 임의의 클라이언트 규칙이나 DTO로 구현하지 않습니다. 정책이 확정되면 이 표를 갱신하고 실제 규칙을 이 문서에 기록하며 [결정 기록](decisions.md)을 추가합니다.
